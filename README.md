# Metro Coding Kids

Landing page dan Admin Hub untuk **Metro Coding Kids** (kursus koding interaktif anak usia 6-15 tahun).

## Fitur Utama
- **Digital Brochure Landing Page:** Format mobile-first responsif dengan integrasi langsung ke WhatsApp CS.
- **Admin Hub:** Pusat kontrol pendaftar (Contact Vault), ekspor data CSV, dan pengaturan dinamis konten landing page.
- **Integrasi Supabase:** Database penyimpanan lead pendaftar secara otomatis.

## Menjalankan Proyek
```bash
npm install
npm run dev
```
Buka [http://localhost:3000](http://localhost:3000) di browser Anda.
